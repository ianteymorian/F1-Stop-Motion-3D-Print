# F1-Stop-Motion-3D-Print
Resources for a F1 Stop Motion that I built.

## Overview

This repository contains an F1-themed stop motion animation project created using a custom 3D-printed set.

The animation was produced by capturing a sequence of images on an iPad using the **Stop Motion** application from the App Store. The cars and other objects were repositioned slightly between each image to create the appearance of movement.

## Production

The physical set and related components were produced using 3D printing.

After the stop motion sequence was completed, the footage was imported into **DaVinci Resolve** for final editing. Sound effects and additional audio were added during the editing process.

Sound effects were obtained from free online sources.

## Repository Contents

This repository includes:

* The completed animation video
* Images used during production
* Files for the 3D-printed set
* Other project-related files

## Workflow

1. Design and 3D print the required set components.
2. Arrange the cars, track, and scenery.
3. Capture each frame using the Stop Motion app on an iPad.
4. Move the objects slightly between each frame.
5. Export the completed stop motion sequence.
6. Edit the video in DaVinci Resolve.
7. Add sound effects and complete the final video.

## Purpose

The purpose of this project was to combine 3D printing, stop motion animation, and video editing to produce a short Formula 1-themed animation.
